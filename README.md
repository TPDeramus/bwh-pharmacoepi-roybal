## Directory Structure:

The parent directory of this code repository should contain 4 folders containing data to be read in:

`000_Static_PCP_Info`
- Contains all "static" (e.g. should theoretically not change over the course of the study) of a given Primary Care Physician used in prediction modeling. These include, but are not limited to:
    - baseline demographics
    - practice statistics
- Recorded as `.csv`s of data for each week (subject to change) following full completion of reward calls to Personalizer and rank calls to Personalizer
- Named "YYYY-MM-DD_pcp_info.csv" with weekly date prepended in format as indicated
- Date used is of when data is generated by program (i.e. this week is exported at program completion, last week is loaded in for program for analytics)

`000_Patient_Info`
- Contains demographic and clinical patient data grouped by primary care physician
- Exists as csv of data exported weekly from Atrius
- Named "YYYY-MM-DD_patient_info.csv" with weekly date prepended in format as indicated
- Date used is of weekly update of patient data
- Patient data is feed into the `context` calls to Microsoft Personalizer at the level of the provider

`000_EHR_Patient_Outcomes`
- Contains boolean 0/1 outcome data for different events itemized by patient data and grouped across primary care physician
- Updated weekly by Atrius
